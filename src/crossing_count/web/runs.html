Finalised validations
Each finalised validation has an ID and a folder that never changes: its manifest (software, rules, footage checksum, lines, the system's numbers and their source, detector and weights, the computer), the result, CSV files and the report. Every file is checked against the checksum in the manifest each time this page opens.
Put windows together
One short window rarely has enough verified crossings for a percentage (at least 30), and never a range: that needs at least 5 windows. Tick finalised windows of one store, peak and control alike, and they are put together: the difference per direction, the bias with its 95% range where there are enough windows, and the error at each traffic level.
