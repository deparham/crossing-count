Hear about new versions
New versions of CrossingCount are kept on a private GitHub repository, so this app needs a GitHub token that can read it. Ask whoever looks after CrossingCount for one. To make one: on GitHub, your picture → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token; Repository access: Only select repositories → the CrossingCount repository; Repository permissions: Contents → Read-only.
Kept in this computer's Keychain (Credential Manager on Windows), never in a file.
Share on this network
People on this network (the office Wi-Fi, for example) open CrossingCount in their browser with an address and the code below, and each works on their own validation. Their counts run on this computer, one at a time. RetailNext keys, updates, settings and quitting stay with this computer, and they pick footage from its footage folders only. The code is new each time sharing is switched on. This computer may ask whether CrossingCount may accept incoming connections: allow it, or nobody can connect.
Colleagues' apps
GitHub builds the Mac app and the Windows installer. They can carry this computer's RetailNext brands, so colleagues open those stores with nothing to type, and a GitHub token, so their apps hear of new versions. Anyone who has the app can dig these out of it: if a laptop is lost, change the keys (in RetailNext, or the token on GitHub), then build again.
Each starts new builds on GitHub now; colleagues' apps offer the update when they are ready, in about 20 minutes.
Get footage from RetailNext
Pick the store and the day. By default the tool finds the busiest stretches for the traffic you validate (peak trading, where sensors fail) and a control window of lower traffic drawn at random, so the results can tell crowding apart from a sensor that is simply off. Every report says which kind of window it measured. Footage comes without RetailNext's own marks, and RetailNext's numbers stay hidden until the count is done, so nothing of the sensor's can sway it.

Draw each camera
For each camera picture: type the site and camera name, draw the counting line (click along it, Enter to finish), click the inside of the store, draw the mask zone if the camera has one, then press Save. Cameras drawn before are found by themselves.
This footage is clean, so there is no RetailNext line to draw over, and a line drawn by eye may not be where the sensor counts. Draw on RetailNext's marked footage of the same minute instead: the line then provably sits on the sensor's own line, and it is used here. The report says which of the two it was.
