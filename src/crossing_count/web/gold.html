Gold set

What the gold set is
Clips a person counted by hand, watching every moment: every crossing was looked for, not only those the tool pointed at. The automatic counter is scored against them and never trained on them. Each store is in one set for good: train and validation (together, the development set) for measuring changes, test held back for a final check. A clip counted by two people keeps only the crossings both counted; the moments they disagree on are left out and listed.

Score the automatic count
Each clip needs an automatic count of the same cameras over the same period (the footage without RetailNext's marks, counted automatically in the wizard). Its recorded detections are replayed with today's settings, so a score shows what the tool does now.
