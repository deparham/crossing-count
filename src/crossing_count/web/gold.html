Gold set

What the gold set is
Clips a person counted by hand, watching every moment: every crossing was looked for, not only those the tool pointed at. The automatic counter is scored against them and never trained on them. Each store is in one set for good: train and validation (together, the development set) for measuring changes, test held back for a final check. A clip counted by two people keeps only the crossings both counted; the moments they disagree on are left out and listed.
Clean and marked footage. A count on footage showing RetailNext's own tracks and counts can lean towards RetailNext's answer. Such clips are kept as marked: scored in the development set but always shown apart from clean clips, never in the test set, and never in anything said about RetailNext's accuracy. A window counted both ways keeps both, and shows how far the marks sway a count.

Do RetailNext's marks sway a count?
Windows counted on clean footage and again on footage showing RetailNext's marks, ideally by different people or days apart. The two counts are matched crossing by crossing; where RetailNext's own number for the window is known, it shows whether the marked count moved towards it.
Versions
A frozen version lists every clip with its checksum and keeps the clips themselves, so a score always names exactly what it was measured on. A test-set score needs one.
Score the automatic count
Each clip needs an automatic count of the same cameras over the same period (the footage without RetailNext's marks, counted automatically in the wizard). Its recorded detections are replayed with today's settings, so a score shows what the tool does now.
Earlier scorings
Every scoring is kept (in bench/experiments in the data folder), with the app version, detector, settings and clips it used. Click one to see it.
